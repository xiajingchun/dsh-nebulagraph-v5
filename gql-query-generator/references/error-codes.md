# Error Code Rewrite Reference

## Rewrite Philosophy
- 按错误码触发定向改写，不盲目重写整条查询。
- 遵循"最小改写 + 保留主干"策略。

## Priority Order（多错误码时）
1. **语法结构层**：`42001`、`42N57`、`42N48`、`42N47`
2. **组合形态层**：`42N42`、`NS004`、`NS007`
3. **名称与可见性层**：`42N18`、`NS002`、`NS209`、`NS216`、`NS228`
4. **子查询边界层**：`NS241`、`NS251`
5. **排序分页层**：`NS248`、`NS212`、`NS213`、`22G04`
6. **类型与特性层**：`42016`、`NR014`、`NS103`、`42000`、`42N36`、`NS236`

## Error Code → Fix Mapping

| 错误码 | 含义 | 修复动作 |
|--------|------|---------|
| `42001` | NEXT/UNION 连接词位置非法 | 保证连接词两侧是合法查询段；禁止块首/块尾/连续连接词 |
| `42N48` | DDL 与非 DDL 混用 | 把 DDL 拆分出去，只保留查询体 |
| `42N45` | MATCH...YIELD 不支持 | 移除 YIELD，改在 RETURN 中投影 |
| `42N47` | 线性查询未收口 | 补 `RETURN ...` 或 `FINISH`；移除 RETURN 后非法子句 |
| `42N57` | 命令语句只能顶层独占 | 移除混合链，仅保留单条顶层命令 |
| `42N42` | 同层连接词混用 | 改成同层单一连接词 |
| `NS004`/`NS007` | 复合查询列数/列名不一致 | 对齐两侧 RETURN 列数与别名顺序 |
| `42N18` | 变量未定义 | 补定义、别名透传或 RETURN...NEXT 可见性链路 |
| `NS002` | 重复定义变量 | 重命名重复的 LET/GRAPH 变量 |
| `NS209` | 当前工作图不存在 | 补 `USE <graph>` |
| `NS216` | 返回列与父作用域冲突 | 透传时改用唯一别名 |
| `NS228` | 标签不存在 | 校正标签名或先切换图 |
| `NS103` | 量词上界非法 | 把 `{0}` 改成 `{0,1}` 或更大上界 |
| `NS241`/`NS251` | 子查询仅允许 DQL | 移除 CALL{...} 内 DDL/DML |
| `NS248` | 排序因子不可见或是子查询 | 落列再排序；DISTINCT/GROUP BY 场景只按可见列排序 |
| `NS212`/`NS213` | OFFSET/LIMIT 类型非法 | 改成无符号整数常量 |
| `22G04` | 排序因子不可比较 | 改为可比较标量属性 |
| `42016` | 采样与 ANN 混用 | 二选一 |
| `NR014` | CASE 分支类型不兼容 | 统一分支类型，必要时加 CAST |
| `42000` | 图/表引用不能直接返回 | 先展开再返回字段值 |
| `42N36` | 绑定表字段数不匹配 | 对齐字段数与记录长度 |
| `NS236` | 绑定表字段名/类型/字面量非法 | 修正字段名，统一类型，回退为常量 |

## Decision Tree（快速修复）
1. 结构错误？→ 连接词合法化、顶层独占、DDL 拆分、线性收口
2. 组合错误？→ 统一连接词、对齐 RETURN 列结构
3. 可见性错误？→ 补变量链路、清理 CALL{...} 中 DDL/DML
4. 排序分页错误？→ 落排序列、修类型、替换不可比较因子
5. 特性互斥？→ 删 SAMPLE 或回退 ANN

任一步修复后主干已可执行且用户未要求完全等价重写时，停止深改。

## Common Error Bundles
| 错误码组合 | 动作序列 |
|-----------|---------|
| `{42001, 42N47}` | 去连接词问题 → 补收口 |
| `{42N57, 42001}` | 收敛单条顶层命令 → 删查询链 |
| `{42N48, 42N57}` | 移除 DDL 或查询链 → 保留单一语句 |
| `{42N42, NS004, NS007}` | 统一连接词 → 对齐列 |
| `{42N18, NS248}` | 补变量定义 → 修排序因子 |
| `{NS241, NS251, 42N47}` | 清 DDL/DML → 补收口 |
| `{NS248, NS212/NS213, 22G04}` | 改排序因子 → 修类型 |
| `{42016, NS248}` | 解互斥 → 修排序 |
